# Sample solutions

Bunch of sample solutions from various models.

## Prompts

Normal prompt:

```txt
Complete the following lean 4 proof:
import Mathlib

...
```

Golf prompt:

```txt
Complete the following lean 4 proof and golf it to the smallest size possible:
import Mathlib

...
```

Follow-up prompts when there are errors:

```txt
Line <Number> error(s):
...

Line <Number> error(s):
...
```
